# To-Do List App

A clean, responsive To-Do List web application built using vanilla HTML, CSS, and JavaScript. All data persists locally in the browser using `localStorage`.

## Features
- **Task Management**: Add tasks with Task Name, Description, and Due Date.
- **Smart Due Date Badges**: Automatic indicators for overdue tasks, tasks due today, and upcoming dates.
- **Edit Any Task**: Update task details on the fly.
- **Safe Deletion**: Confirmation dialog prompts before deleting any task.
- **Live Search**: Instant filtering by task name or description.
- **Live Task Counter**: Displays the total number of tasks at the top.
- **Friendly Empty State**: Cheerful guidance when there are no tasks or search returns no results.
- **Responsive Layout**: Designed for mobile phones, tablets, and desktop displays.
- **Zero Backend**: Runs entirely client-side without servers, logins, or external databases.

## Tech Stack
- HTML5
- CSS3 (Custom properties, responsive flexbox/grid)
- Vanilla JavaScript (ES6+, LocalStorage API)

## Getting Started
Simply open `index.html` in any modern web browser.
